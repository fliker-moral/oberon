OBERON
Windows 10 / 11 · x64

Распакуйте архив целиком и дважды нажмите ярлык Oberon в распакованной папке.
Приложение также можно открыть через app\Oberon.exe.
В сборку входит Python. Требуется системный Microsoft Edge WebView2 Runtime.

1. В «Настройках» выберите DeepSeek, Gemini, OpenAI API, Qwen или Timeweb AI.
2. Сохраните ключ выбранного провайдера, проверьте подключение и выберите модель.
   Gemini использует ключ Google AI Studio. Для моделей OpenAI нужен ключ OpenAI API.
   Оплата OpenAI API идёт отдельно от подписки ChatGPT.
   Для Qwen введите ключ и API Host из Alibaba Cloud Model Studio.
   Пустое поле API Host использует общий адрес региона Сингапур.
3. Нажмите «Новый проект». Можно начать вручную, импортировать GitHub, ZIP,
   локальный Git, публичный сайт или фронтенд Mini App. Укажите коммерческую
   цель, если она известна. Отчёт покажет, что предложить клиенту, какую пользу
   это даст и как её измерить.
4. В проекте откройте «История», чтобы сравнить коммиты и отчёты.
   Откройте «Текст для клиента» в карточке, чтобы посмотреть, отредактировать и
   скопировать предложение. Для нескольких идей соберите общее КП.
5. В «Обучении» добавьте Git или ZIP. Приложение откроет коммерческие идеи,
   из которых тоже можно собрать и скопировать черновик КП.
   Поставьте каждому решению оценку от 1 до 5. Можно объяснить оценку
   и предложить свой вариант. Оценки сохраняются для следующих разборов.
   Выберите область применения: этот проект, похожие проекты или все проекты.
   В «Памяти этого разбора» можно изменить, отключить или удалить оценку.
   «Пересмотреть идеи с учётом оценок» создаст новый разбор на том же снимке.
   Чтобы проверить обновлённый код, создайте новый разбор Git или ZIP.
   Переключатель обратной связи в настройках действует на обучение и анализ.

Локальный Git и ZIP читаются целиком после фильтрации кэшей, сборок,
зависимостей и секретов. Большие проекты обрабатываются несколькими запросами.
«Основания анализа» показывает охват, исключения, фрагменты и оценки.
В каждой рекомендации доступны цитаты, условия оценки и проверка результата.
«Цитата найдена» означает совпадение с источником, а не доказанную работоспособность.
Идеи без проверяемых цитат отмечены как гипотезы. Часы и цены предварительные.
При необходимости ответьте на вопросы модели в описании и повторите анализ.
Обучение сохраняет ваши решения локально и передаёт подходящие примеры модели.
Для ZIP область «только этот проект» привязана к имени архива.
Для полного охвата ранее созданного разбора загрузите исходник заново.

Для локального репозитория нужен Git для Windows. Oberon смотрит коммиты.
Для приватного GitHub сохраните токен с правом чтения Contents нужного репозитория.
Сетевой импорт ZIP ограничен 64 МиБ архива и 128 МиБ исходников после
распаковки. Для большего проекта выберите ZIP с диска или локальный Git.
Закрытые экраны Mini App и динамический интерфейс за авторизацией не проверяются.

Данные находятся в %LOCALAPPDATA%\Oberon\oberon.sqlite3.
Журналы находятся в %LOCALAPPDATA%\Oberon\logs. oberon.log содержит этапы
анализа, ошибки и расход токенов, если API его вернул. launcher.log содержит
события окна и WebView2. Ключи, исходники и ответы модели не пишутся в журналы.
Если анализ прервался, повторите запуск с тем же архивом и настройками.
Проверенные ответы сохраняются на семь дней и используются при повторе.
Если Timeweb прервёт работу после получения части ответов, Oberon оставит
частичный разбор. При следующем запуске проблемный пакет будет разделён
на меньшие части, если его ещё можно разделить.
Ключи из интерфейса защищаются средствами Windows для текущей учётной записи.
Резервная копия в настройках содержит данные и настройки без ключей.
Для восстановления закройте Oberon, сохраните копию текущей базы и замените
её файлом резервной копии с именем oberon.sqlite3. Затем откройте Oberon.
Так же можно перенести базу предыдущего локального Oberon App.

Название посвящено Оберону Уайту из Warface. Палитра вдохновлена серией «Оникс».
