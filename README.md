# Oberon

Oberon — мой пет-проект для Windows. Я сделал его, чтобы по коду проекта быстро понять, что уже есть, какие доработки можно предложить клиенту и как объяснить их пользу.

Можно открыть репозиторий на GitHub, локальный Git или ZIP. Для публичного сайта и Telegram Mini App доступен разбор открытых страниц. Oberon сохраняет историю, сравнивает версии и позволяет собрать из выбранных идей редактируемый черновик коммерческого предложения.

При разборе большого проекта исходники делятся на пакеты. В отчёте видно, какие файлы прочитаны, а у части выводов есть ссылки на строки кода. Идеи можно оценивать, чтобы следующие разборы учитывали подходящие примеры из прошлых оценок.

## Запуск из исходников

Понадобится Windows и Python 3.11+. Для импорта локального репозитория установите Git. Python-пакеты через pip ставить не нужно.

```powershell
git clone https://github.com/fliker-moral/oberon.git
cd oberon
python -m oberon.web
```

Откроется [локальный интерфейс](http://127.0.0.1:8765/). Чтобы попробовать приложение без ключа, создайте проект вручную или импортируйте снимок репозитория. Для анализа с ИИ выберите провайдера в настройках и добавьте свой API-ключ. Поддерживаются DeepSeek, Qwen, Gemini, OpenAI и Timeweb AI. Ключ также можно указать в файле `.env` по образцу [`.env.example`](.env.example).

Проекты и история хранятся в локальной SQLite. При анализе подходящие фрагменты исходников и описание проекта отправляются выбранному провайдеру. Oberon пропускает типичные файлы с секретами и скрывает распространённые форматы ключей. Перед разбором закрытого проекта проверьте, какие данные можно отправлять внешнему API.

## Что внутри

- `oberon/` — локальный HTTP-сервер на стандартной библиотеке Python, импорт, анализ и работа с SQLite.
- `static/` — интерфейс на HTML, CSS и JavaScript.
- `native/` — оболочка WinForms с WebView2 и скрипт сборки Windows-приложения.
- `tests/` — тесты импорта, истории, анализа и HTTP API. Ответы моделей подменяются в тестах.

```powershell
python -m unittest discover -s tests -v
node --check static/app.js
```

Node.js нужен только для второй команды.

## Сборка Windows x64

Для сборки нужен PowerShell 7 и компилятор .NET Framework, входящий в Windows. Для запуска окна нужен установленный Microsoft Edge WebView2 Runtime.

1. Скачайте [Python 3.13.17 embeddable для Windows x64](https://www.python.org/downloads/release/python-31317/) и распакуйте в `dependencies/python`.
2. Распакуйте пакет [Microsoft.Web.WebView2 1.0.4314.35](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.4314.35) в `dependencies/webview2`. В этой папке должны быть каталоги `lib` и `runtimes`.
3. Выполните из корня проекта:

```powershell
.\native\build.ps1 -Dependencies .\dependencies -Destination .\dist\Oberon -IconPng .\native\Oberon-Onyx.png
.\dist\Oberon\app\Oberon.exe
```

Параметр `--check` запускает проверку окна и локального сервера. Подробности о работе с приложением есть в [«Начало работы.txt»](Начало%20работы.txt).
